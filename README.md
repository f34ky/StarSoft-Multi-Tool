# StarSoft Multi-Tool

A multifunctional cybersecurity utility for OSINT username search and system tasks.

## Features

- Username Search - Check accounts on 20+ platforms (VK, GitHub, Telegram, YouTube, TikTok)
- Password Generator - Create strong passwords (8-32 characters)
- System Monitor - CPU and RAM usage with progress bars
- Website Pinger - Check site availability and response time
- Password Strength Checker - Analyze password security
- Website Headers - View HTTP headers
- IP Information - Geolocation, ISP, coordinates
- ASCII Art Generator - Convert text to block art

## Installation

1.1 Clone the repository:
    git clone https://github.com/f34ky/StarSoft-Multi-Tool.git
1.2 cd StarSoft-Multi-Tool

2. Install dependencies:
   pip install -r requirements.txt

3. Run the program:
   python starsoft.py

## Usage

After launch, enter the tool number (0-8) and follow instructions.

Tool list:
1 - Random Password
2 - CPU and RAM Info
3 - PING site
4 - Username Search
5 - Website Headers
6 - IP Info
7 - Text to ASCII Art
8 - Password Strength
0 - Exit

## Supported Platforms for Username Search

VK, GitHub, Telegram, YouTube, TikTok, Chess, HackerRank, LeetCode, Replit, PyPI, npm, Codecademy, Codewars, BitBucket, GitLab, Keybase, Patreon, Tumblr, DeviantArt, SoundCloud
